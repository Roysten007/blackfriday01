# VOLTA — Black Friday Bénin

Boutique e-commerce Black Friday mobile-first pour la marque fictive **VOLTA** (électronique et accessoires, Cotonou, Bénin).

> *"L'électronique qui tient sa promesse."*

## Stack Technique

- **Framework** : [Next.js](https://nextjs.org/) (App Router, React 19)
- **Styling** : [Tailwind CSS](https://tailwindcss.com/)
- **Animations** : [Framer Motion](https://www.framer.com/motion/) + Canvas Confetti
- **Icônes** : [Font Awesome 6 Solid](https://fontawesome.com/)
- **Typographie** : Anton (titres & prix géants) + Inter (corps de texte)

## Fonctionnalités

- **Barre d'annonce & Compte à rebours** : décompte en direct jusqu'au 30 novembre à 23h59.
- **Hero épuré et centré** : badge d'urgence, titre en 2 lignes nettes, message fort et lisibilité optimale.
- **Grille des 6 offres** : photos studio réelles, jauges de stock d'urgence, badges de réduction, bénéfices en icônes.
- **Pack Vedette "Kit Autonomie"** : empilement de valeur complet avec calcul d'économie.
- **Panier tiroir latéral (Slide-over)** : gestion des quantités, code promo `VOLTA10` (-10%) avec confettis.
- **Conversion WhatsApp** : génération instantanée du bon de commande pré-formaté envoyé directement vers WhatsApp via le panier.
- **Carrousel d'avis clients** : slider défilant interactif et ticker continu.
- **Foire aux questions** : accordéon anti-objections (garantie 12 mois, livraison Cotonou 24h, paiement MTN/Moov).

## Déploiement sur Vercel

Le projet est 100% prêt et configuré pour un déploiement instantané sur Vercel (`vercel.json` inclus) :
1. Importer le dépôt GitHub `https://github.com/Roysten007/blackfriday01.git` sur [Vercel](https://vercel.com).
2. Framework Preset : **Next.js** (détecté automatiquement).
3. Root Directory : `./`
4. Cliquer sur **Deploy**.

## Commandes locales

```bash
npm install
npm run dev
npm run build
```
